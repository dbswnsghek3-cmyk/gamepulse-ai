## 공통 조건
- 2026-11-16 패치 이후 촬영한 최신 화면 (기준일 2026-11-19)
- 한국어 UI만 사용 (영어·일본어·중국어 화면 불가)
- 16:9 비율 (1920×1080 권장 · 표시 상자 좌표가 이 크기 기준)
- 직접 촬영했거나 사용 권한을 확인한 이미지

## 화면 교체 방법
1. 새 파일을 이 폴더에 넣는다.
2. manifest 의 해당 슬롯 `file`·`captured_at`·`verified_note` 를 고친다.
3. 화면 구성이 달라졌으면 `gamepulse/views/overwatch.py` 의 `SHOT_NOTES` 표시 상자 좌표와 `blur` 좌표를 다시 맞춘다.

확인: `python scripts/check_overwatch_images.py`
