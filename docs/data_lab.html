댓글 CSV 분석

직접 수집한 댓글 CSV 를 올리면 표준 스키마로 검증하고, 불만 유형·감성을 분류해 시각화합니다.

현재 분류 방식: 규칙 기반(키워드) · 업로드한 파일은 이 컴퓨터에서 실행 중인 앱 안에서만 처리되며 외부로 전송되지 않습니다. 개인정보(닉네임, 계정 ID 등)는 CSV 에 넣지 않는 것을 권장합니다.

1. CSV 형식 (표준 스키마)

컬럼필수형식설명예시
comment_id필수str댓글 고유 ID (중복 불가)c_000123
game_id필수str게임 ID 또는 게임 이름 (overwatch / pubg / fconline / dnf / lol, '오버워치' 등 한글명도 허용)lol
source필수str수집 출처 (커뮤니티, 앱 리뷰, SNS, 설문 등)커뮤니티
posted_at필수date작성 일시 (YYYY-MM-DD 또는 YYYY-MM-DD HH:MM)2026-10-01
text필수str댓글 본문연패 오니까 솔랭은 너무 스트레스라 칼바람만 해요
rating선택float별점 등 수치 평가 (1~5, 없으면 비움)2
user_segment선택str이용자 구분 (신규 / 기존 / 복귀 등, 알 수 있을 때만)기존
category선택str사람이 직접 붙인 불만 유형 라벨 (있으면 분류기 결과와 비교 가능)연패 스트레스·경쟁 피로
sentiment선택str사람이 직접 붙인 감성 라벨 (부정 / 중립 / 긍정)부정
url선택str원문 링크 (선택)
